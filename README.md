# civ1-power

Civilization's (v474.05) terms for `core-power`:

- **Rank:** gold / 32 + 8 × citizens + (advances counted + 1) + Σ unit cost / 10. The advances are counted by the game's `AdvanceCount` rules: civ1-science counts only those gained in play, as v474.05's `tech_count` does.
- **Strength:** each unit's attack and defence, with Nuclear units left out.

These are the measures computer players use in diplomacy.
